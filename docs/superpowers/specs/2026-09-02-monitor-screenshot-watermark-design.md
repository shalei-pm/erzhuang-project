# 监控截图水印设计

日期：2026-09-02

## 目标

为正式“查看监控”页面的用户主动截图增加可配置水印，便于安全合规追溯。水印包含当前 SSO 用户昵称和服务端签发的截图时间。管理员可以在系统设置中全局关闭该能力。

## 范围

- 覆盖正式监控页面的直播和回放截图按钮。
- 仅在用户明确点击截图时处理；播放器冻结帧、缩略图加载、打开大图不处理。
- 原始缩略图、OSS 初始化回填和刷新缩略图不改变。
- 不覆盖 NVR 实验页或旧版门店通道截图功能。

## 用户体验

截图成功时，导出的 PNG 在右上角展示两行深色半透明水印：

```text
凯撒（沙磊）
2026-09-02 09:18:36
```

- 第一行使用 SSO `display_name`；为空时回退用户名，再为空时回退邮箱。
- 第二行使用服务端按 `Asia/Shanghai` 格式化的 `YYYY-MM-DD HH:mm:ss`。
- 水印按导出图片尺寸自适应，并保留右上角安全边距。
- 开关关闭时，截图维持当前导出/分享行为但不添加水印。
- 当水印开启且元信息请求、Canvas 绘制或导出失败时，取消本次截图并显示中文错误提示；不得降级导出无水印图片。

## 全局设置

在“系统设置”新增“安全设置”页签，只有系统管理员可见。

- 设置项：`monitor_screenshot_watermark_enabled`。
- 默认值：`true`。
- 存储：复用现有 `tb_app_settings` 的键值记录，不新增表、字段或 DDL。
- 管理员修改后立即生效，现有已导出文件不追溯处理。
- 修改记录审计事件 `system.monitor_screenshot_watermark.update`，安全摘要记录修改前后状态，不记录 Cookie、Token 或图片数据。

## 接口与权限

新增受登录态和门店监控授权保护的截图元信息接口。其职责是：

1. 验证当前用户对目标门店和摄像头的监控查看权限。
2. 读取水印全局开关。
3. 在开启时返回昵称与中国标准时间；关闭时只返回关闭状态。
4. 记录用户明确点击截图的审计事件 `monitor.screenshot`，包含门店、摄像头、操作人、服务端截图时间和结果。

浏览器只接收展示所需的元信息，随后在新 Canvas 上叠加水印并调用现有分享/下载逻辑。图片字节不上传到服务端，不写入 OSS，不持久化。

## 安全边界

- 服务端是昵称、时间和水印开关的唯一可信来源；前端不使用设备本地时间生成合规时间。
- 开关读取和截图元信息接口均使用现有空闲会话校验；会话失效时复用统一 SSO 退出流程。
- 这是一项应用层留痕，不是 DRM。用户仍可能通过操作系统截图等方式获得无水印屏幕内容。
- 审计不得记录视频流地址、Token、Authorization、图片数据或 Data URL。

## 验收标准

- 水印开启时，直播和回放导出的 PNG 都显示右上角昵称和服务端中国标准时间。
- 水印关闭时，直播和回放截图可导出且不显示水印。
- 普通用户看不到安全设置，也不能调用设置写接口。
- 管理员修改设置后，操作日志显示操作人、旧状态和新状态。
- 无权限、会话失效、元信息请求失败或 Canvas 失败时不导出无水印图片。
- 用户明确点击截图产生一条 `monitor.screenshot` 审计；冻结帧、缩略图加载和打开大图不产生该事件。
- 全部 Go 测试、前端测试和生产构建通过；测试环境实页验证一个直播样本与一个回放样本。

## 发布与回滚

- 实现版本为 `3.4.2`，仅发布 GitLab 测试分支 `codex/containerize-single-image`。
- 不触碰 GitLab `main`、正式实例、正式数据库或 K8s Secret。
- 回滚只需回到当前稳定测试提交；设置值即使保留也不会被旧版本读取，不影响旧版本功能。
