# 10001 工控机取流实验页设计

状态：已确认，待实施
日期：2026-08-21
范围：北京保利总部店 `external_org_id=10001`

## 目标

在不改变现有萤石 H5 Monitor 的前提下，建立一个受权限保护的独立实验页，验证公司工控机 NVR 的直播和回放取流链路。

实验页必须：

- 从二壮同步的业务资源表只读获取 `10001` 摄像头及空间关系。
- 由二壮后端实时请求公司鉴权服务，换取一次播放会话的短期 WSS 地址。
- 使用与公司 WSS 私有协议匹配的 NVRPlayer 适配层进行播放验证。
- 视觉和交互复用现有 2.x H5 Monitor 的首页、详情页、播放器区域、底部“实时视频 / 录像”Tab 和移动端全屏体验。
- 默认不展示调试信息；管理员可经右上角信息按钮打开脱敏诊断。

本设计不承诺 iPhone/微信已可播放。iPhone/微信直播是正式替换的硬验收门槛，必须由实验页真机验证通过后再进入正式灰度。

## 非目标

- 不修改现有 H5 Monitor 路由、萤石 API、萤石播放页、录像片段逻辑或并发限制。
- 不将新链路故障静默回退至萤石，避免重复开流和掩盖问题。
- 不写入 `tb_crm_*` 同步表，不新增空间/设备映射维护入口。
- 不保存、展示、复制、记录长期 Authorization、短期 token 或完整 WSS URL。
- 第一版不实现录像片段查询、截图、清晰度切换、长期观看限制或生产级自动重连。

## 用户体验

### 实验首页

路由：`/h5/nvr-lab/10001`

首页复用现有 `H5MonitorHome` 的视觉语言：`SystemTopBar`、门店标题、区域筛选 Tab 和圆形摄像头缩略图墙。摄像头来源为资源查看的有效海康通道，按空间类型/名称派生可读名称；无截图时沿用现有深色占位画面。

该入口不进入正常门店切换导航，只允许管理员访问。非管理员与非 `10001` 请求直接返回无权限或不存在，不泄露设备信息。

### 实验播放详情

路由：`/h5/nvr-lab/10001/cameras/{cameraId}`

详情复用 `H5MonitorChannel` 的页面骨架：顶部返回和摄像头名称、16:9 播放区域、点击画面显示/隐藏控制条、静音、横竖屏、全屏以及底部“实时视频 / 录像”Tab。

- 直播：进入或主动重试时实时创建播放会话。
- 回放：底部 Tab 显示开始、结束时间选择和“播放”操作。由于新接口尚未提供录像片段查询，不能渲染或伪造旧版录像片段列表。
- 诊断：右上角信息图标默认收起。展开后仅显示阶段、耗时、模式、播放器能力、连接/首帧状态和脱敏错误类别；不显示敏感 URL、token 或请求头。

默认试验样本为 `camera_id=111`，对应业务库中的治疗室4、NVR `22`、通道 `56`。首页仍允许管理员切换到该门店其他有效摄像头。

## 后端设计

新增独立 `nvrlab` 包及路由，不改 `h5monitor` 的萤石服务。

### 资源读取与权限

1. 复用 APISIX SSO 身份认证和二壮角色授权。
2. 仅 `admin` 可访问实验路由和 API。
3. 仅接受 tenant `10001`。
4. 从已同步的 `tb_crm_iot_device`、`tb_crm_iot_area_device_relation`、`tb_crm_consulting_room` 读取有效海康通道：
   `category='camera' AND provider='HikVisionNvrChannel' AND status=1 AND deleted_at IS NULL`。
5. 只允许为该只读结果集中的摄像头创建播放会话，禁止客户端任意传入外部门店或设备 ID。

### API 契约

```text
GET  /api/h5/nvr-lab/10001/cameras
POST /api/h5/nvr-lab/10001/cameras/{cameraId}/stream-session
```

会话请求：

```json
{ "mode": "live" }
```

或：

```json
{ "mode": "playback", "start_time": 1787208895, "end_time": 1787208925 }
```

后端校验回放时间为 Unix 秒，且 `start_time < end_time`、范围不超过实验页定义的最大窗口。直播不得携带回放时间。

调用公司鉴权接口时，统一使用：

- `camera_id`：业务库摄像头 ID。
- `stream_type=2`：直播和回放均使用。
- 直播不传时间；回放传 `start_time` 与 `end_time`。

响应仅返回当前会话所需的短期地址、模式及可选过期时间；HTTP 响应强制 `Cache-Control: no-store`。短期地址在浏览器内存中使用后即丢弃，不写入 sessionStorage、localStorage、日志或诊断复制内容。

### 凭据与错误处理

长期服务端凭据仅由运行时环境注入：优先 `K8S_SECRET_NVR_STREAM_AUTHORIZATION`，兼容 `NVR_STREAM_AUTHORIZATION`。测试和正式环境分别配置 K8s Secret，即使当前值相同也不共用 Secret 对象。

后端不得在启动日志、错误文本、审计日志或 HTTP 错误响应中输出该凭据、短期 token 或 WSS URL。鉴权失败、超时、无映射、权限不足和参数错误应返回稳定错误码与中文用户提示。

第一版不进行后台缓存和无界自动重试。播放器在地址过期或连接失败时，只允许一次受控的“重新连接”动作，由前端重新请求后端生成新会话，绝不复用旧 WSS URL。

## 前端播放器适配

新增 NVRPlayer 适配组件，保持与现有 `H5FlvPlayer` 相同的状态上报形态：初始化、连接、首帧、播放状态、错误和销毁。

- 清除 SDK 中向控制台输出完整 `wsUrl` 的行为。
- 回放模式显式传入 `isReplay`/`forceWasm`，不依赖 WSS URL 字符串推断回放，因为 URL 仅含 token。
- 断开连接后不自动无限重连旧地址。
- SDK 的 worker、WASM 和主脚本在二壮仓库内固定版本、受控发布；不得依赖 `static.soyoung.com/sy-pre` 的可变预发资源。接入前检查用户提供 SDK 的许可证与版本来源。
- 播放画面使用 canvas。本期允许桌面验证先行，但不把 WebCodecs H.265 路径视为 iOS 支持。

## 验收与发布

### 本地和测试环境

1. Go 单元测试：权限、固定 `10001`、有效摄像头校验、直播/回放参数、鉴权请求、敏感信息脱敏。
2. 前端单元测试：路由、直播/回放 Tab、回放时间校验、状态显示、诊断不含敏感信息。
3. 前端构建和 Chrome 实际页面验收：实验首页、详情、空态、鉴权失败、WSS 失败、首帧成功。
4. 测试 K8s Secret 配置后，使用 `camera_id=111` 验证鉴权、WSS `101`、桌面首帧、连续播放和手动重连。

### 移动端门槛

在任何正式替换或扩大门店前，必须用同一真实设备验证：

- iPhone Safari 直播首帧、连续播放、前后台切换、全屏/返回。
- 微信内置浏览器直播首帧、连续播放、前后台切换、全屏/返回。

若任一项失败，实验页保留为隔离验证工具，不替换旧 H5 Monitor；后续在浏览器端软解和独立流媒体网关之间重新决策。

## 回滚

实验页为新隐藏路由，删除路由注册或关闭 `10001` 实验开关即可撤销。它不改旧萤石链路，不需要数据库回滚，也不应影响其他门店监控。
