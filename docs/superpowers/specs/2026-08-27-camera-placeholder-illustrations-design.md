# 摄像头默认缩略图设计

**状态：** 已选视觉源，待实现
**日期：** 2026-08-27

## 目标

在摄像头尚无真实截图时，展示能辅助快速扫读的灰白场景默认图。真实缩略图始终优先。

## 视觉源

- 唯一视觉源：Figma 文件“二壮摄像头默认缩略图方案”中的最终 `07 · Illustrated Scene`。
- 不采用 Pencil 生成预览，不混用两套插画语言。
- 图片为无描边的 `64 x 40` 静态图；画面使用浅灰底与场景元素铺满构图，不嵌套矩形边框，不显示文字。

## 默认图分类

| kind | 适用空间 |
| --- | --- |
| `consultation` | 面诊、咨询 |
| `treatment` | 治疗、床位、业务空间 `level=3` |
| `reception` | 前台、接待、导诊、收银 |
| `waiting` | 候诊、等候、休息、大厅 |
| `corridor` | 走廊、过道、通道、入口、出口 |
| `utility` | 茶水、卫生间、更衣、储物、库房、办公室、会议室及其他已绑定公共功能区 |
| `unassigned` | 无空间绑定 |

## 实现边界

- 后端根据已有 `space_type` 与 `space_name` 返回稳定的 `thumbnail_kind`；前端不分散维护关键词判断。
- 先按 Figma 导出的 7 张 PNG 静态资源接入资源详情和 NVR 监控页。
- 不改业务库、二壮 MySQL、OSS、取流接口、真实截图优先级或权限校验。
- 未命中但已绑定空间统一使用 `utility`；无绑定使用 `unassigned`。

## 验收

- 有真实缩略图时仍展示真实图。
- 无真实图时，资源详情和 NVR 监控页按同一 `thumbnail_kind` 展示同一默认图。
- 缩略图内无可见描边、文字或额外卡片边界。
- 桌面列表和 H5 摄像头墙中图像不拉伸、不模糊、不出现大面积无意义留白。
