# 3.4.12 登录返回页面实验

- 范围：仅二壮前端、登录回调；不改 SSO、数据库、实例或构建配置。
- 通过站内 `return_to` 参数传递原地址，保留业务查询参数和 fragment；手动登出使用原页面作为既有 SSO `from_uri`。
- 登录回调和前端均验证目标只属于应用业务路径，拒绝外链、路径逃逸、认证及 API 地址。返回页面仍执行原有权限校验。
- 首页直接访问没有旧地址记录，不恢复历史页面。前端收到认证成功后才消费入口返回参数。
- 本地验证：Go 全仓测试通过（macOS 使用外部链接）；前端 18 文件 / 119 测试通过，生产构建通过。
- 测试部署前基线：`868b80d` / 3.4.11。失败时仅 revert 本次测试功能提交，保留既有会话安全修复；不重置共享分支、不改数据。
- 待真实验收：未登录深链接 -> 扫码 -> 原监控页；详情页登出 -> 扫码 -> 原详情；主动首页 -> 首页；超时回跳；非法目标回首页。
- 测试未验收前不提交正式 main；如果需要 SSO 调整则停止并回滚实验。
