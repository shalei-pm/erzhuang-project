# 设计图标记与诊室区域管理 PRD

最后更新：2026-06-08

## 1. 项目背景

新氧青春门店装修时会产出门店设计图 PDF。当前希望建立一个线上管理工具，用于维护门店设计图与图纸中的诊室/区域信息，帮助业务在线查看每个门店有哪些空间资源，以及每个空间在设计图中的位置。

本项目第一版聚焦：

- 上传门店设计图 PDF。
- 将 PDF 转换为图片预览。
- 使用 AI 自动识别门店名称和目标区域。
- 在图纸上自动生成区域高亮框。
- 支持人工修正区域信息和高亮框。
- 保存门店、设计图、区域信息到数据库。
- 在门店列表中查看空间资源统计。

## 2. 项目目标

第一版上线后，需要支持：

- 线上维护门店设计图。
- 自动识别并管理图纸中的治疗室、面诊室、生美区域。
- 查看某个门店的空间资源数量。
- 查看区域在设计图中的大概位置。
- 支持编辑和删除门店设计图配置。

### P0 范围

- 添加门店。
- 编辑门店。

- PDF 上传。

## 4. 页面结构

整体 UI 风格：

- 参考当前主流大厂后台系统风格。
- 简洁、大气、克制、专业。
- 信息密度适中，适合业务人员长期使用。
- 避免营销页式大卡片和强装饰。
- 颜色需要集中定义为可配置色值，方便后续统一调整。
- 区域类型色、高亮色、状态色都应通过设计 token 或 CSS 变量管理，不写死在组件内部。

### 4.1 首页

页面顶部：

- `添加门店` 按钮。
- 门店名称搜索框。

页面主体：

- 门店列表。
- 空列表时显示图纸/文件相关占位图片。
- 页面底部展示当前版本号，便于产品验收和线上问题反馈时对齐具体发布版本。

### 4.2 门店列表字段

门店列表每页 20 条，默认按最近更新时间倒序。

列表字段：

- 序号：当前页面展示顺序，无业务意义。
- 门店名称。
- 设计图缩略图。
- 治疗室数量。
- 面诊室数量。
- 生美数量。
- 区域总数。
- 配置状态。
- 更新时间。
- 编辑。
- 删除。

缩略图交互：

- 鼠标 hover 缩略图时展示浮层预览。
- 鼠标移开后浮层消失。
- 建议浮层尺寸约 `360px x 240px`，保持比例展示。

### 4.3 配置状态

配置状态包括：

- 已完成：所有区域字段完整，有高亮框，且没有低置信度区域。
- 需确认：存在低置信度区域，但字段和高亮框完整。
- 待完善：存在缺名称、缺类型、缺编号或缺高亮框。由于保存会强校验，正常保存后的门店不应出现该状态，仅用于历史脏数据或异常场景。

第一版不做草稿。添加弹窗未保存，不生成门店记录。

## 5. 添加/编辑门店弹窗

添加和编辑门店共用一个大弹窗。弹窗类似 lightbox，覆盖整个浏览器可视区域，并随窗口自适应。

布局：

- 顶部固定工具栏。
- 左侧图纸预览区，占 60%。
- 右侧区域信息区，占 40%。

顶部工具栏：

- 左侧：门店名称输入框。
- 中间：当前文件名、上传/重新上传 PDF。
- 右侧：取消、保存。

弹窗流程状态：

1. 初始：上传 PDF。
2. 转换中：PDF 转图片。
3. 识别中：AI 识别门店与区域。
4. 重复确认：如存在同名或疑似同名门店。
5. 编辑确认：用户修正门店名、区域、编号、高亮框。
6. 保存中。
7. 保存成功/失败。

识别中动效：

- 左侧图纸上展示轻微扫描线。
- 右侧展示卡片骨架和“正在识别门店与区域”提示。

保存按钮规则：

- 识别中不可点击。
- 识别完成或识别失败后可点击。
- 点击保存后统一做校验。

关闭规则：

- 如果有未保存修改，点击关闭或 ESC 时提示“有未保存修改，确认离开？”
- 确认离开后，未保存修改不生效。

保存成功后：

- 自动关闭弹窗。
- 刷新门店列表。

## 6. PDF 上传与转换

文件限制：

- 第一版只支持 PDF。
- PDF 最大 5MB。
- PDF 最多 5 页。

多页规则：

- 多页 PDF 表示多楼层。
- 按 PDF 页码顺序从上到下拼接为一张完整图。
- 第 1 页在最上方，第 2 页接在下方，以此类推。

错误提示：

- 文件过大：`文件过大，请上传 5MB 以内的 PDF。`
- 页数过多：`当前最多支持 5 页 PDF，请拆分后上传。`
- 转换失败：`设计图解析失败，请重新上传 PDF。`

转换失败时：

- 保留上传入口。
- 不进入 AI 识别流程。

当前实现说明：

- 2026-06-08 已接入真实 PDF 上传、服务器转 PNG 和 AI 识别链路。
- mock 图纸/识别仅保留给 `VITE_DESIGN_PLAN_API_MODE=mock` 的本地演示模式。
- 真实上传或识别失败时，不再静默使用样例图纸，必须提示用户失败并允许手动维护。

## 7. AI 识别规则

### 7.1 识别目标

第一版只识别三类区域：

- 治疗室。
- 面诊室。
- 生美。

非目标区域忽略，不进入右侧区域列表。例如：

- 前台。
- 走廊。
- 仓库。
- 洗手间。
- 办公区。

### 7.2 区域类型定义

页面展示三类：

- 治疗室。
- 面诊室。
- 生美。

业务含义：

- 治疗室：医美治疗室。
- 生美：生美治疗室、生美区、生美相关区域。
- 生美治疗室不计入治疗室。

### 7.3 识别字段

AI 识别结果应包含：

- 门店名称。
- 门店名称置信度。
- 区域名称。
- 区域类型。
- 编号。
- 区域置信度。
- 矩形框坐标。
- 原始识别 JSON。

区域名称规则：

- 默认保留图纸原文。
- 模型判断区域类型。
- 用户可以手动修改区域类型和编号。
- 区域名称不单独编辑，由系统按 `区域类型 + 编号` 自动生成；生美无编号时名称为 `生美`。

编号规则：

- 如果图纸文字中有明显编号，模型可以自动预填。
- 用户必须能修改。
- 识别不到编号时为空。

门店名称规则：

- 从图纸标题/图签中识别。
- 如果有多个候选，第一版只填置信度最高的一个。
- 用户可以手动修改。
- 门店名称保存时必填。

### 7.4 识别失败和部分成功

识别失败：

- 允许用户手动维护。
- 门店名称手动填写。
- 区域列表为空。
- 用户可以新增区域并画框。
- 保存规则不变。

部分成功：

- 门店名称识别失败、区域识别成功：门店名称为空，用户手动填写；区域正常展示。
- 区域识别失败、门店名称识别成功：门店名称自动填入；区域列表为空，用户手动新增。

识别 0 个目标区域：

- 提示：`未识别到治疗室、面诊室或生美区域，可手动新增。`
- 允许手动维护。

识别耗时：

- 目标 30 秒内完成。
- 超过 60 秒提示识别超时，可手动维护。

### 7.5 低置信度

- 低置信度区域展示“需确认”标签。
- 低置信度不阻止保存。
- 第一版不做逐条确认按钮。
- 如果用户修改字段或高亮框，仍可正常保存。

低置信度由模型或识别服务判断。

## 8. 区域维护规则

### 8.1 区域字段

每个区域包含：

- 序号：展示顺序，无业务意义。
- 区域类型：必填，只能是治疗室、面诊室、生美。
- 编号：只允许数字。
- 高亮框：必填。

区域名称和确认状态：

- 区域名称由系统自动生成，不在右侧表单中单独编辑。
- 治疗室、面诊室名称格式为 `类型 + 编号`，例如 `治疗室 1`、`面诊室 2`。
- 生美有编号时名称为 `生美 + 编号`，无编号时名称为 `生美`。
- 区域类型、编号和高亮框完善后，保存时自动视为已确认。
- 不做手动“状态”勾选或下拉。

### 8.2 编号规则

- 治疗室编号必填。
- 面诊室编号必填。
- 生美编号非必填。
- 生美不填编号时，多个生美区域都允许为空。
- 如果生美填写编号，也要参与生美类型内唯一校验。
- 编号只允许数字。
- 编号唯一性按同类型内唯一。
- 治疗室 1 和面诊室 1 可以同时存在。
- 治疗室 1 和治疗室 1 不允许同时存在。
- 编号不要求连续。
- 不提示编号不连续。
- 删除区域后，该编号释放，可被再次使用。

错误提示：

- `治疗室编号不能为空`
- `面诊室编号不能为空`
- `编号只能填写数字`
- `同类型下编号不能重复`

### 8.3 区域排序

- AI 识别出的区域默认按图纸位置排序。
- 排序规则：从上到下、从左到右。
- 用户可以通过上移/下移按钮调整顺序。

### 8.4 区域新增和删除

新增区域：

- 用户点击“新增区域”。
- 右侧新增一条未完成区域并自动选中。
- 左侧进入画框模式。
- 用户在图纸上拖出矩形。
- 矩形绑定到当前选中区域。

删除区域：

- 右侧区域卡片可删除。
- 删除区域不需要二次确认。
- 未保存前关闭弹窗，删除不生效。
- 保存后删除生效。

### 8.5 保存校验

保存时必须满足：

- 门店名称必填。
- 必须已上传并成功转换 PDF。
- 至少有 1 个区域。
- 每个区域必须有区域类型。
- 每个区域必须有高亮框。
- 治疗室、面诊室必须填写编号。
- 编号必须为数字。
- 同类型下编号不能重复。

如果保存失败：

- 顶部提示：`还有 X 个区域未完善。`
- 右侧错误区域卡片标红。
- 自动滚动到第一条错误。
- 左侧如果缺框，提示用户补充高亮框。

## 9. 图纸预览和高亮框

### 9.1 图纸查看

左侧图纸预览支持：

- 放大。
- 缩小。
- 适应屏幕。

这些功能仅用于查看设计图。

进入画框模式时：

- 回到原始编辑尺寸。
- 确保高亮框和坐标保存准确。

### 9.2 高亮框展示

- 左侧始终显示所有区域框。
- 当前选中区域更明显。
- 点击右侧区域卡片时，左侧对应区域高亮。
- 点击图纸区域框时，右侧对应区域卡片选中。
- 高亮框可以拖动。
- 高亮框四角可以拉伸。
- 高亮框不允许超出图片边界。
- 高亮框重叠时提醒但允许保存。

### 9.3 高亮颜色

整体采用高级后台系统风格的克制配色。

建议类型色：

- 治疗室：红色系。
- 面诊室：绿色系。
- 生美/美容区：蓝色系。

当前选中区域：

- 沿用对应类型颜色，通过更粗边框和外层阴影增强选中态。
- 不使用统一黄色选中态，避免颜色指代混乱。

### 9.4 高亮标签

图纸高亮框上展示：

- 框内直接展示编号数字。
- 编号下方展示区域类型。
- 生美无编号时，框内展示 `生美`。
- 不再在矩形框上方展示浮动标签，避免出现空白或灰色标签块。

## 10. 门店重复判断

### 10.1 判断规则

门店名称保存前做清理：

- 去掉前后空格。
- 连续空格压缩。
- 英文大小写忽略。

重复判断：

- 完全同名：认为是重复门店。
- 模糊同名：弹窗列出疑似门店，由用户确认是否为同一门店。

模糊匹配规则可包括：

- 包含关系。
- 去掉品牌词后相似。
- 相似度超过阈值。

页面只展示疑似列表，不暴露算法细节。

编辑门店时，重复判断排除当前门店自身。

### 10.2 判断时机

- AI 识别完成门店名称后，立即做一次同名/模糊同名判断。
- 用户点击保存时，用最终门店名称再做一次完全同名校验。

### 10.3 模糊同名弹窗

弹窗展示：

- 疑似门店名称。
- 已有设计图缩略图。
- 区域数量。
- 创建/更新时间。

每条疑似门店可选择：

- 这是同一门店。
- 不是，创建新门店。

如果存在多条疑似门店，只能选择其中一个作为同一门店。

### 10.4 覆盖旧门店

如果用户确认是同一门店，并确认覆盖：

- 保留旧门店 ID。
- 删除旧 PDF。
- 删除旧拼接 PNG。
- 删除旧缩略图。
- 删除旧区域数据。
- 删除旧识别 JSON。
- 保存新 PDF、图片、缩略图、区域和识别 JSON。
- 更新时间更新为当前时间。

覆盖确认文案：

```text
系统检测到已存在同名门店。继续保存将覆盖该门店当前设计图和区域信息，覆盖后不可恢复。是否继续？
```

按钮：

- 取消。
- 覆盖。

## 11. 删除门店

删除门店是彻底删除。

删除内容：

- 门店记录。
- 原始 PDF。
- 拼接 PNG。
- 缩略图。
- 区域数据。
- 原始识别 JSON。

全局删除日志保留。

删除确认文案：

```text
删除后无法恢复，是否确认删除该门店？
```

按钮：

- 取消。
- 确认删除。

- 门店名称。
- 操作人。

- 操作摘要。

第一版只记录门店级日志：

- update。
- delete。

删除日志至少保存：

- 操作人。
- 操作时间。

## 13. 数据字段建议

### 13.1 门店

建议字段：

- 门店 ID。
- 门店名称。
- 标准化门店名称。
- 原始 PDF 文件路径。

- 缩略图路径。
- PDF 页数。
- 配置状态。
- 最新识别 JSON。

第一版暂不需要：

建议字段：

- 区域类型。
- 编号。
- 识别置信度。

- 矩形坐标 y。
- 矩形坐标 width。
- 矩形坐标 height。
- 创建时间。
- 更新时间。

坐标规则：

- 基于原始拼接图片比例坐标保存。

编号保存：

- 不支持前导 0 的业务含义。
- 页面不自动补零。

### 13.3 文件存储

第一版文件建议保存到服务器本地磁盘：

```text
/opt/apps/erzhuang-project/uploads
```

数据库保存文件路径。

后续可迁移到 Supabase Storage。

删除门店时：

- 尽量删除对应文件。

```json
        "width": 0.08,
        "height": 0.06
      }
    }
  ],
  "raw_notes": "..."
}
```

内部区域类型建议：

- `treatment`：治疗室。
- `consultation`：面诊室。
- `beauty`：生美。

## 15. 验收标准

### 15.1 添加门店

- 用户可以点击“添加门店”打开大弹窗。
- 用户可以上传 5MB 以内、5 页以内的 PDF。
- PDF 能转换成图片并在左侧展示。
- 多页 PDF 能按页码上下拼接。
- AI 能识别门店名称并填入输入框。
- AI 能识别治疗室、面诊室、生美区域。
- AI 能生成区域列表和对应高亮框。
- 用户可以修改区域类型、编号和高亮框，区域名称自动生成。
- 用户可以新增区域并画框。
- 保存成功后弹窗关闭，列表刷新。

### 15.2 编辑门店

- 点击编辑能打开同一弹窗。
- 弹窗带出门店名称、图纸和区域信息。
- 点击右侧区域能高亮左侧对应区域。
- 用户可以修改区域字段和高亮框。
- 用户可以重新上传 PDF。
- 重新上传 PDF 前有二次确认。
- 保存后覆盖当前门店最新数据。

### 15.3 删除门店

- 点击删除出现二次确认。
- 确认后门店从列表消失。
- 删除后同名门店重新上传不再判断为已有门店。

### 15.4 校验

- 门店名称为空不能保存。
- 区域数量为 0 不能保存。
- 区域类型为空不能保存。
- 治疗室、面诊室编号为空不能保存。
- 编号不是数字不能保存。
- 同类型编号重复不能保存。
- 区域没有高亮框不能保存。

### 15.5 列表

- 列表展示门店名称、缩略图、各类型数量、区域总数、状态和更新时间。
- 支持门店名称搜索。
- 每页 20 条。
- 缩略图 hover 展示浮层预览。

### 15.6 异常

- PDF 超过 5MB 时提示。
- PDF 超过 5 页时提示。
- PDF 转换失败时提示重新上传。
- AI 识别失败时允许手动维护。
- AI 识别 0 个目标区域时允许手动新增。
