## 验收设计

使用公司测试链路机构10001的机房摄像头103。选择完整的至少30分钟录像，避免将到达录像末尾误判为倍率问题。若需要扩大设备覆盖，优先无患者的机房/空场景。每个样本记录墙上时间、屏内录像时间、WASM录像时间、滑块位置、连接代次和控制命令；不记录令牌或完整签名URL。

| 场景 | 验证方法与标准 |
| --- | --- |
| 普通播放基线 | 连续30秒，画面与录像时间正常推进；记录原始帧落点，确认起播定位正常。 |
| 2/4/8/16倍 | 各档至少3次切换，每次稳定观察不少于30秒。去除切换建立期后，录像画面时间/墙上时间与目标倍率一致，允许关键帧量化；不接受只改滑块或ACK成功。 |
| 滑块 | 每档取至少3个画面时间点，对照绝对录像时间与当前签流锚点，误差不超过关键帧间隔且不持续积累。 |
| 恢复普通 | 各档主动恢复，不回到旧录像、不越过最后实际呈现位置；连接建立后按1倍连续播放30秒。 |
| 暂停与继续 | 各档暂停30秒，位置及画面冻结；继续从暂停落点附近播放，维持选择倍率，不能跳过等待时段。 |
| 暂停时改倍率 | 不发起无用会话；继续才取流，落点与倍率正确。 |
| 快进10秒 | 普通与倍速分别检查；以当前真实呈现位置加10秒，恢复后时间连续。 |
| 跨档 | 同一会话按2→4→8→16→1，以及重复同档的路径验证，防止把增量倍速当绝对倍率。 |
| 异常 | 网络断连、明确拒绝、迟到回包和时钟异常不伪报成功；用户可以立即恢复普通或暂停。 |
| 音频/资源 | 普通播放可恢复原音频意图；高倍速音频策略沿用既有设计。旧连接/Worker/decoder释放，资源不随切换增长。 |
