# Frontend Review Checklist

本清单用于前端改动发布前快速验收。目标是用最短时间拦住粗糙 UI、断链交互和线上难排查问题。

## 1. 基础检查

- `npm run build` 通过。
- 页面底部版本号可见。
- 浏览器控制台无明显运行时报错。
- 关键接口失败时有用户可理解提示。
- 错误提示不出现裸英文技术文案，例如 `validation failed`。
- 图片缩略图如果 URL 可代表内容版本，应支持浏览器缓存或前端内存缓存；刷新图片时通过新 URL 失效旧缓存。

## 2. 门店列表

- 搜索框可输入，按门店名关键词能过滤结果。
- 无结果时有明确空态。
- 表格列宽稳定，操作按钮不换行挤压。
- 数量、状态、更新时间展示清楚。
- 删除操作有二次确认。

## 3. 添加门店弹窗

- 点击“添加门店”能打开弹窗。
- 关闭按钮不变形。
- 门店名称、新氧机构 ID、设计图、录像机字段层级清楚。
- 录像机添加使用轻量加号按钮。
- 有账号时能选择萤石云账号。
- 删除录像机行可点击。
- 只填设计图或只填录像机都能满足“至少一个资源”的创建规则。
- 同名门店有清晰提示。

## 4. 门店详情

- 顶部只读信息以陈列方式展示，不像输入框。
- 新氧机构 ID、录像机数、有效通道数、业务区域数展示准确。
- Tab 切换明确，当前 Tab 状态可见。
- 返回列表可用。

## 5. 设计图标注 Tab

- 无设计图时上传入口清楚。
- 上传中、识别中、失败、成功都有状态反馈。
- 左侧图纸能显示。
- 区域矩形框颜色和业务类型一致。
- 选中区域比未选中区域明显。
- 点击左侧矩形框能定位右侧区域卡片。
- 点击右侧区域卡片能定位左侧矩形框。
- 保存校验能指出缺失名称、类型、编号或高亮框。

## 6. 通道映射 Tab

- 录像机列表是横向表格。
- 未扫描录像机只显示“扫描通道”。
- 已扫描录像机显示“再次扫描”和“识别区域”。
- 识别提示文案在操作附近，不打断主流程。
- 通道表格字段对齐：录像机、通道号、截图、区域类型、编号、确认状态、操作。
- 未确认和已确认状态的编辑权限符合产品规则。

## 7. 视觉质量

- 页面没有大面积无意义空白。
- 控件间距统一。
- 按钮字号统一。
- 卡片不嵌套卡片。
- 色彩不单调，也不花哨。
- 不使用装饰性渐变、光斑、漂浮图形。
- 桌面常用宽度下无文字重叠或截断。

## 8. 发布前结论

最终回复或 PR 说明中至少包含：

- 验证过的页面。
- 验证命令。
- 是否做过浏览器实际验收。
- 已知风险。
- 是否建议发布。
